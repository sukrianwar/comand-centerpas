Modul Offline Mode &amp; Antrian Sinkronisasi Beberapa titik checkpoint (basement, ruang panel, parkiran bawah tanah ) berpotensi berada di luar jangkauan WiFi kantor . Modul ini memastikan aktivitas patroli tetap tercatat secara akurat meski perangkat security terputus sementara dari jaringan WiFi kantor , dengan data dikirim otomatis begitu koneksi kembali tersedia . Cara Kerja Aplikasi Web (PWA â€” Progressive Web App) secara berkala memeriksa status koneksi ke jaringan WiFi kantor . Selama terhubung , setiap hasil scan checkpoint langsung dikirim dan disimpan ke server ( Mysql ). Saat koneksi terputus , aplikasi otomatis beralih ke Mode Offline: hasil scan (checkpoint, waktu , lokasi , foto ) disimpan sementara di penyimpanan lokal perangkat ( IndexedDB pada browser), bukan dikirim ke server. Setiap data offline dicatat ke dalam antrian (queue) lokal dengan status " Menunggu Sinkronisasi ", lengkap dengan timestamp saat data direkam di perangkat . Guard tetap dapat melanjutkan patroli checkpoint berikutnya tanpa hambatan ; setiap hasil scan baru otomatis masuk ke antrian yang sama . Begitu perangkat kembali terhubung ke WiFi kantor , aplikasi otomatis mengirim seluruh data dalam antrian ke server secara berurutan (FIFO â€” First In, First Out) tanpa perlu aksi manual dari guard. Setelah suatu data berhasil dikirim dan dikonfirmasi tersimpan server, data tersebut dihapus dari antrian lokal dan statusnya berubah menjadi " Tersinkron ". Timestamp resmi yang tercatat di server tetap mengacu pada waktu saat data direkam di perangkat (offline), bukan waktu saat data terkirim , sehingga akurasi waktu kunjungan checkpoint tetap terjaga . Fitur Pendukung Indikator status koneksi (Online/Offline) ditampilkan jelas di halaman utama Web App Patrol. Badge jumlah data yang masih dalam antrian ("3 data menunggu sinkronisasi ") agar guard mengetahui progres pengiriman . Retry otomatis dengan jeda bertahap (exponential backoff) apabila percobaan kirim gagal , agar tidak membebani jaringan saat baru tersambung kembali . Data di penyimpanan lokal tetap aman tersimpan meskipun browser/tab ditutup atau perangkat dimatikan , dan akan otomatis dilanjutkan pengirimannya saat aplikasi dibuka kembali . Notifikasi ke Admin apabila terdapat data yang gagal sinkron dalam waktu lama ( lihat tabel eskalasi bab 15). Ketentuan &amp; Batasan Foto bukti temuan /incident yang diambil saat offline turut disimpan sementara di perangkat dan ikut dikirim saat sinkronisasi ; ukuran file dikompresi otomatis agar tidak memenuhi kapasitas penyimpanan lokal . Resolusi konflik data (mis. jika ada perubahan jadwal saat guard offline) ditangani di sisi server berdasarkan timestamp asli data direkam . Panic Button tetap memerlukan koneksi aktif karena sifatnya darurat /real-time ( lihat bab 16) â€” tidak dimasukkan ke dalam antrian offline. Perbandingan dengan Fase 2 (Mobile App) Offline mode pada Web App Fase 1 memanfaatkan penyimpanan browser ( IndexedDB ) yang cukup untuk kebutuhan operasional harian , namun memiliki keterbatasan kapasitas dan bergantung pada dukungan PWA di perangkat /browser guard.
